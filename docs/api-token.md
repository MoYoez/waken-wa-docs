## 管理上报凭据与接入配置

API Token 在这里的意思是，唯一用户授权认证 Key，即代表**此Key将有修改并且提交记录的能力**

当然了，为了防止用户 A 使用了 同样的 Key 导致同时提交了错误的状态给不同的设备，Key同时做了 HashKey 绑定，这就是为什么一开始需要进行二次审核处理！

:::tip
您可能不知道 HashKey 是什么意思，在项目里面 我们统一称作为 身份牌。

一般来说，Waken-Wa 的 Reporter 有自动创建的功能，一般是一段 随机 Sha256 且 Byte 不超过 256 的字符串皆可

你也可以自己创建。
:::


:::tip
对了，如果您觉得此步骤多此一举，可以在后台配置中启用自动通过

不过 一身份牌 = 1 Key, 如果使用了 A key 绑定了 A 设备后，使用 B Key 上报了 A 设备，仍会提醒需要修改

身份牌属于设备唯一凭证之一，在外部截图的时候注意打码此部分，**他和 API KEY 同样重要**
