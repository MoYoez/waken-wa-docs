# 欢迎

✨ 一个自托管的个人状态围观面板

> 😴晨光里睁眼是醒，深夜写下"今天很好"也是醒。

Waken-Wa Web 可以把你的设备、听歌、应用、Steam 游戏、日程和随想，整理成一个实时更新的个人主页。它不是传统意义上的监控面板，更像一个可以被朋友打开、围观、了解你此刻状态的数字生活展示页。

> 🌟项目灵感来源于 [Sleepy](https://github.com/sleepy-project/sleepy) 和 [Shiro](https://github.com/Innei/Shiro)

> ✨ 在线 Demo： [Status](https://Status-me.lemonkoi.one)

## 可以用来做什么？

### 🕵️ 自托管的个人状态面板

把你的在线状态、当前设备、正在听的歌、使用中的应用、Steam 游戏、日程和随想，变成一个可以被朋友围观的实时主页。你可以自己部署、自己管理数据，也可以按自己的习惯决定要展示什么。

### 🎨 不是普通状态页，而是个人数字生活展示

Waken-Wa Web 支持主题取色、背景定制、状态文案规则和个性化卡片。页面可以更像“你的个人空间”，而不是冷冰冰的服务状态面板。

<p align="center">
  <img src="/img/waken-wa-web/preview_v2_image_main_3.png" alt="Waken-Wa Web 个性化展示预览" width="620" />
</p>

### 📡 多设备状态自动同步

通过 Reporter / API 上报桌面、移动端或脚本状态后，页面会自动更新你现在正在做什么。无论是在线、离线、忙碌、上课、听歌还是游戏中，都可以成为页面上的一部分。

<p align="center">
  <img src="/img/waken-wa-web/preview_v2_image_main.png" alt="Waken-Wa Web 多设备状态同步预览" width="620" />
</p>

### 🎵 支持音乐、应用、游戏和日程

除了基础在线状态，Waken-Wa Web 还可以展示听歌进度、当前应用、Steam 游戏、ICS 课表 / 日程等生活状态，让主页更接近真实的日常节奏。

<p align="center">
  <img src="/img/waken-wa-web/preview_v2_image_main_2.png" alt="Waken-Wa Web 音乐应用游戏日程预览" width="620" />
</p>

### 🧩 可嵌入、可扩展

Waken-Wa Web 适合作为个人主页、BBS 签名卡、GitHub README 状态卡，或者朋友之间的“围观入口”。你也可以通过 OpenAPI、状态规则和嵌入卡片继续扩展它。

## 文档会带你完成什么？

这里是 Waken-Wa Web 的使用文档。你可以从下面几步开始：

1. 阅读 [安装与部署](./install-and-deploy)，把服务跑起来。
2. 按照 [初次配置](./first-setup)，完成站点、账号和基础功能设置。
3. 继续配置 Reporter、音乐、应用、Steam、ICS 日程、嵌入卡片和更多个性化选项。
