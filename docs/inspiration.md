# ✍️ 灵感随想录

灵感随想录 和 大部分现代化的博客框架差不多，本身使用的是 [Lexical](https://lexical.dev/)，是一个很不错的开源文本框架

![picture 0](/articles/6bc50405730ce23caf5097fd84548de1dc4dec3c319cf3a7e053d24d82127b3c.png)  


## 文本，撰写

文本框适配 Markdown 语法，如果您不知道什么是 Markdown，请查看[此处](https://markdown.com.cn/basic-syntax/)

当然，不会语法也没有关系，上面也有类似于 Word 的 标识，帮助你一键添加

## 关于头图

图片要求 16:9 比例，长度最高为1200px的图片，图片需要通过二次裁剪

在实际的显示中，如果没有头图，则会使用第一张在文章的图片作为列表中图片的显示。

如果连图片都没有的话，就会显示一段纯文本，效果如图：

## 关于 “提交当前任务快照”

![picture 2](/articles/f28b3ecba0ccf1a3666c7b39d7ebf7d89b85fecd1625d98c573bf02837d4a284.png)  

一般来说，你可以通过已经存在，且**未被遗忘**的任务作为选择之一，在写作的时候同时带上当时的感想和在做的事情。

如果设备信息可用，你可以通过右边的 带上设备信息 显示正在使用的设备 一般以 （**设备名称 · 电量**） 来显示
