# ✍️ Inspiration Log

The inspiration log works much like a modern blog editor. It uses [Lexical](https://lexical.dev/), a very good open-source text framework.

![picture 0](/articles/6bc50405730ce23caf5097fd84548de1dc4dec3c319cf3a7e053d24d82127b3c.png)  

## Writing text

The text box supports Markdown syntax. If you do not know Markdown, see [this guide](https://markdown.com.cn/basic-syntax/).

You do not need to memorize the syntax, though. The toolbar includes Word-like buttons that can add formatting for you.

The result may look like this:

![picture 0](/articles/253677fd75225f7914ae257ad1098ae20fdfd6fe7a61171cd38fd9a6445608c4.png)  

## Cover images

Cover images should use a 16:9 ratio and be no wider than 1200 px. They will need a second crop.

In actual display, if there is no cover image, the first image inside the article is used as the list image.

If there are no images at all, the entry displays plain text, like this:

![picture 1](/articles/67f2b29d78dfe3115e90d69d1d9d52ab82ae56752c00c99c81410209ddf72e04.png)  

## "Submit current task snapshot"

![picture 2](/articles/f28b3ecba0ccf1a3666c7b39d7ebf7d89b85fecd1625d98c573bf02837d4a284.png)  

Usually, you can choose from existing tasks that have **not been forgotten**, then write down both your thoughts and what you were doing at the time.

If device information is available, the "include device information" option on the right can show the device you are using.

It is generally displayed as **device name · battery**.

## Search

There is not much to explain here. Open a result to view the related content, and use the controls on the right to delete or edit the status information from that time.
