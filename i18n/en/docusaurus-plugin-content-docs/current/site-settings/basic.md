# Basic Settings

![picture 0](/articles/ee702bfa69446c737b8d23b50712b6393a39cb63d80dd0da8be08a1a74fde7f3.png)  

Most of these settings were already covered in [First Setup](/docs/get-start/first-setup). This page adds a few extra notes.

## Site icon URL

![picture 1](/articles/3df69a8572f3d0f92c2f50b540c28f8d142b93b6e23b891bd6d40e76a81174da.png)  

This generally refers to the site icon. After uploading, refresh the page to see it take effect. If left empty, the default SVG is used.

## Use Hitokoto for the homepage note

![picture 2](/articles/4b72a5b9671886ddd940b9ed526c214cd4f23aa26a87d76dd938975ea71e7a44.png)  

The site fetches content from [hitokoto](https://hitokoto.cn/). **This feature overwrites the note**.

Related adjustment options are available in the advanced settings.

## Enable page lock

![picture 3](/articles/b920641060d2455a9a6dc9d17cd8fc46632994fb9d15d3e70c610c310a48fc22.png)  

Adds a lock layer when users visit the page.

:::warning
This option also blocks other status-related API calls. Use it carefully.
:::

:::tip
This feature works together with hCaptcha in the advanced settings.
:::
