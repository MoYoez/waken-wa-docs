# 🖼️ Orphan Images

![picture 0](/articles/776d39141d22b9200601c6953f4c995d8795edcd4d86ae0e1a3bbdce1468f1bd.png)  

Orphan images are **images uploaded to the server but not actually referenced anywhere**.

The term comes from mix-space, and I liked it enough to borrow it here.

It usually looks like this:

![picture 1](/articles/c4e6ddebc88c7fc1acdc7031cadd619bc20c02ad3945ffb23224cb95f9ceef14.png)  

This usually happens when a user uploads several images to the inspiration log, but some of them are never used.

Check whether they are actually needed. If not, just clean them up.
