# 🗓️ Schedule

- The schedule design is similar to Wakeup. If you have used similar timetable apps before, this should feel familiar.

## Homepage display

![picture 0](/articles/40ea9c8a252fdd02c1e9999204ede20281a6cefd22d0d63a9a2b33c9e6ba63f1.png)  

- During class hours, the homepage shows "In class":

![picture 1](/articles/d77c00e1f10bb82bc995104806ecefa880e9f4da7c657c7080efdf60e7dc13fe.png)  

- Between classes, it shows a "Next class" preview:

![picture 2](/articles/380423d069611a10b5117d4f96959da4c123af60977ea7148ff51221e84406c2.png)  

If this is disabled, nothing will be shown here when there is no class.

- Show classroom and teacher in the card

![picture 3](/articles/b213fd052f2e1ac65c59a058e047645634b43ccf4b1247095eadfaaf79ae0c68.png)  

When enabled, extra content appears only on hover on desktop or tap on mobile.

:::warning
The preview does not tell you the classroom or teacher for the next class.
:::

## Fixed period template

![picture 5](/articles/705bcb1f5c7b38a6682d41d6fc784e784689938a5d9f1fae75ec4eb2ce2f0951.png)  

Some schools have odd course schedules or inconsistent rules, so you can set up a rough template here and quickly pick periods later when importing.

:::info
This part includes automatic checks. If your selected class times do not match, usually during import, the system will prompt you to fix the ordering.
:::

## Course list

![picture 6](/articles/07a0ba729e12db02b5c17cb64134f5ebab0342c20f049b230461011c462cb642.png)  

In most cases, you can add multiple course entries to handle classes that happen more than once a week.

If a course has unusual timing, such as ~~taking up lunch break~~, use "Custom time" to handle it.

## Importing

ICS timetables are supported, and most timetable apps can export them.
